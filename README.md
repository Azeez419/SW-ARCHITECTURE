# SW-ARCHITECTURE

## Sprint 1 – Requirements & Architecture

### Overview
Sprint 1 focuses on defining the problem, system requirements, and high-level architecture for the **Share Price Comparison App**. No functional implementation is included in this sprint.

### Sprint 1 Objectives
- Define functional and non-functional requirements
- Design a clear system architecture
- Identify main components and their responsibilities

### Key Deliverables
- **Requirements specification:** `docs/requirements.md`
- **Architecture overview:** `docs/architecture.md`
- **Component diagram:** `diagrams/component-diagram-sprint1.png`

### Architecture Summary
The system is designed using a layered approach:
- **UI layer** – handles user interaction
- **Service layer** – contains business logic
- **Client layer** – communicates with external APIs
- **Repository layer** – manages local JSON data storage

### Scope
- No UI implementation
- No real API integration
- No business logic implementation

Sprint 1 is complete and provides the foundation for implementation in Sprint 2.
